Design asset library Soon

Planned — see docs/roadmap.md "Parallel track — Design Asset Library"

One home for every design file, so nothing lives only on a laptop and past work can be found again.

Upload once, publish everywhere. Drop a source file (PSD/AI/PDF) with a name, description, and category. Originals go to a private, versioned S3 bucket that is never public; a web-optimised copy is derived automatically and published to the storefront's assets path.

Categories are the catalog leaves you already use — the same list the storefront's product sections are built from, so the library and the shop can never drift apart. Files are renamed on save through the shared naming convention, which is what lets a newly published design appear in the product offerings with no code deploy.

Searchable history. Browse and filter by category, tag, or uploader to reference past work instead of rebuilding it.

Access will reuse the existing staff roles — Production, Sales, and Admin can upload; no new role is being added.
